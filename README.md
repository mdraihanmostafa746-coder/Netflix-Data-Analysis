# Netflix Data Analysis

An exploratory data analysis project focused on Netflix movies and TV shows using Python and popular data analysis and visualization libraries.

## 📌 Project Overview

This project analyzes the Netflix titles dataset to discover useful patterns and insights about the content available on Netflix.

The analysis focuses on areas such as:

* Movies vs TV Shows
* Content released over the years
* Popular genres and categories
* Ratings distribution
* Countries producing Netflix content
* Movie and TV show durations
* Directors and cast information
* Content trends over time

## 🛠️ Technologies Used

* **Python**
* **Pandas** — Data manipulation and analysis
* **NumPy** — Numerical operations
* **Matplotlib** — Data visualization
* **Seaborn** — Statistical data visualization
* **Jupyter Notebook** — Analysis environment

## 🚀 How to Run the Project

### 1. Clone the repository

```bash
git clone https://github.com/your-username/Netflix-Data-Analysis.git
```

### 2. Navigate to the project

```bash
cd Netflix-Data-Analysis
```

### 3. Create and activate a virtual environment

```bash
python3 -m venv .venv
source .venv/bin/activate
```

### 4. Install dependencies

```bash
pip install -r requirements.txt
```

### 5. Open the Jupyter Notebook

Open:

```text
notebooks/netflix_analysis.ipynb
```

Then select the project's `.venv` Python environment as the Jupyter kernel and run the cells.
